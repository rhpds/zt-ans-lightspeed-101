_Ansible Lightspeedを使用して、`postgresql-server` をインストールし、PGAdmin Podmanコンテナを作成するプレイブックを生成するためのガイドです。_

---

== はじめに - セットアップ

[IMPORTANT]
====
**このラボに関する重要な注意点**

IBM watsonx Code Assistantモデルは継続的に更新され、改善されています。その結果、モデルの更新により、このラボで説明されている特定のタスク生成の課題が、説明どおりに機能しない場合があります。これは予期される動作です。

**このラボの主な目的は、Ansible Lightspeedの主要な機能、特に以下について理解を深めることです。**

* **プレイブック生成** - 自然言語のプロンプトからプレイブック全体を生成する
* **タスク生成** - 個別のタスク、または複数のタスクを一度に生成する
* **トレーニングの一致** - AIサジェスチョンの透明性を理解する
* **ベストプラクティス** - LightspeedがどのようにAnsibleのベストプラクティスを取り入れているかを学ぶ

**特定のプロンプトが期待どおりにサジェスチョンを生成しない場合:**

* タスク生成ではなく**プレイブック生成**を試す（Ansibleアイコンをクリック → **Generate a playbook**ボタンをクリックし、プロンプトを入力、アウトラインをレビューしてからContinueをクリックします）
* 最適なサジェスチョンを得るために、さまざまなプロンプトのバリエーションを試す
* 複雑なマルチタスクのプロンプトを、個別のシングルのタスクのプロンプトに単純化する
* 学習目標は変わりません。AIアシストによるAnsible開発の取り組み方を理解することです。
====

この課題では、**Ansible Lightspeed**を使用して、完全なデータベースと管理ツールのセットアップを自動化する**Ansible Playbook**を生成します。

=== あなたのミッション

あなたの目標は、Ansible Lightspeedを使用して、次のタスクを自動化するプレイブックを生成することです。

1.   `postgresql-server` をインストールし、データベースを初期化し、`postgresql` サービスを開始・有効化する。
2.   `postgresql` のトラフィック用に**ファイアウォール**を設定する。
3.   `podman` を使用して、`dpage/pgadmin4` **コンテナ**を設定し、実行する。 

The examples used in this lab are available in the link:[https://github.com/ansible/ansible-lightspeed-demos](https://github.com/ansible/ansible-lightspeed-demos)[Ansible Lightspeed Demoリポジトリ]

[NOTE]
====
**ヘルプが必要な場合:** 困難に遭遇した場合や、作業を確認したい場合は、リポジトリ内の `playbooks/infra/install_pgsql_and_pgadmin/solution_install_pgsql_pgadmin.yml` にある解決策プレイブックを参照できます。
====

## タスク1: Ansible Lightspeedを使用したプレイブックタスクの生成

事前に作成されたプレイブックファイルを編集し、自然言語のプロンプトを使用して、Ansible Lightspeedに必要なタスクを生成させます。

1.   **VS Codeでプレイブックファイルを開きます。**
+
    a. ラボ環境の上部にある**VS Code**タブをクリックします。
+
[IMPORTANT]
====
**新しいブラウザタブで作業:** Ansible Lightspeedの機能を最大限に活用するには、インラインの埋め込みウィンドウを使用するのではなく、**VS Codeタブをクリックして新しいブラウザタブで開いてください**。
====
+
    b. VS Codeの左側にある**Explorer**アイコン（2つのドキュメントが重なっているように見えます）をクリックして、ファイルエクスプローラーを表示します。
+
    c. ファイルエクスプローラーで、**playbooks** → **infra** → **install_pgsql_and_pgadmin**のフォルダを展開します。
+
    d. **demo_install_pgsql_pgadmin.yml**をクリックして、エディターで開きます。

2.   **PostgreSQLインストールタスクを生成します。**
+
    a. プレイブックファイル内で、次の行を見つけます。
+
[source,yaml]
----
    #- name: Install postgresql server package
----
+
    b. 行の先頭にある**`#` 記号を削除します**（または Windows/Linuxでは `CTRL+/`、Macでは `CMD+/` を押します）。
+
    c. **カーソルをその行の行末**（"package"の後）に置きます。
+
    d. **`ENTER` を押して**新しい行を作成します。
+
    e. 少し待つと、Ansible Lightspeedが**グレーのテキストでサジェスチョン**を表示します。
+
    f. **`TAB` を押して**サジェスチョンを受け入れます。
+
    _Lightspeedの注目点:_ サジェスチョンは、`ansible.builtin.dnf` モジュールを正しく使用し、ベストプラクティスを取り入れています。

3.   **設定、開始、ファイアウォールのマルチタスクを生成します。**
+
[IMPORTANT]
====
**マルチタスクのプロンプト:** このコメント行は単一の `#` で始まり、複数のタスクを `&` で区切ります。この行のコメントアウトを解除してはなりません - 行の最後に `ENTER` を押すだけです。
====
+
    a. 次の行を見つけます。
+
[source,yaml]
----
    # Do initial postgresql config & start the service & allow the traffic through the firewall
----
+
    b. **この行のコメントアウトを解除しないでください** - `#` 記号はそのままにしておきます。
+
    c. **カーソルをその行の行末**（"firewall"の後）に置きます。
+
    d. **`ENTER` を押して**新しい行を作成します。
+
    e. Lightspeedが**3つすべてのタスク**のサジェスチョンを表示したら**`TAB` を押します**。
+
    _Lightspeedの注目点:_ Lightspeedはプレイブックのコンテキストを使用して、正しいサービス（`postgresql`）とデフォルトポート（`5432/tcp`）を推測し、この単一のプロンプトから3つの異なる**冪等なタスク**を生成します。

4.   **Podmanコンテナタスクを生成します。**
+
    a. 次のコメントアウトされた行を見つけます。
+
[source,yaml]
----
    #- name: Create podman container using pgadmin_container var
----
+
    b. `#` を削除して**行のコメントアウトを解除します**（または `CTRL+/` / `CMD+/` を押します）。
+
    c. **カーソルをその行の行末**（"var"の後）に置きます。
+
    d. **`ENTER` を押して**新しい行を作成します。
+
    e. Lightspeedがサジェスチョンを表示したら**`TAB` を押します**。
+
    _Lightspeedの注目点:_ Lightspeedは、`pgadmin_container` 変数がプレイブックの `vars` セクションで定義されていることを正しく識別し、提案されたタスクに統合します。

5.   **プレイブックを保存します。**
+
    トップメニューから**File** → **Save**をクリックするか、`CTRL+S` (Windows/Linux) または `CMD+S` (Mac) を押します。

## タスク2: Ansible Lightspeedトレーニングの一致の確認

Ansible Lightspeedの主要な差別化要因の1つは、サジェスチョンの生成に使用された可能性のあるトレーニングデータに関する情報を提供することです。

1.   **Lightspeed Training Matchesビューを開きます。**
+
    a. VS Codeの上部にあるメニューバーで**View**をクリックします。
+
    b. **Open View...** を選択します。
+
    c. 表示される検索ボックスに `Lightspeed` と入力します。
+
    d. リストから**Lightspeed Training Matches**をクリックします。

2.   **トレーニングの一致を調べます。**
+
    a. プレイブック内で、生成した任意のタスク名をクリックします。
+
    b. 生成されたコードの1行を削除し、`ENTER` を押してサジェスチョンを再生成します。
+
    c. **Lightspeed Training Matches**ペイン（通常はVS Codeの下部にあります）を確認します。
+
    d. 潜在的なトレーニングソースが表示されます。**任意の項目をクリック**して、コンテンツソース、作成者、ライセンス情報などの詳細を確認します。

## タスク3: プレイブックの実行

これで、完成したプレイブックを、Automation Controllerまたは `ansible-navigator` のいずれかを使用して実行することを選択できます。

### オプション1: Automation Controllerの使用

1.   **プレイブックをGitにコミットしてプッシュします。**
+
    a. VS Codeの左側にある**Source Control**アイコン（円が付いたブランチのように見えます）をクリックします。
+
    b. 「Changes」の下に `demo_install_pgsql_pgadmin.yml` が表示されているはずです。
+
    c. ファイル名にカーソルを合わせ、表示される**+**（プラス）アイコンをクリックして変更をステージングします。
+
    d. 上部の「Message」ボックスに、`Install PostgreSQL and PGAdmin` のようなコミットメッセージを入力します。
+
    e. **Commit**ボタン（チェックマークアイコン）をクリックします。
+
    f. **Sync Changes**ボタンをクリックして、プレイブックをGitリポジトリにプッシュします。

2.   **Automation Controllerからプレイブックを実行します。**
+
    a. ラボウィンドウの上部にある**Ansible Automation Platform**タブをクリックします。
+
    b. ログイン画面が表示された場合は、以下を入力します。
       * **ユーザー名:** `admin`
       * **パスワード:** `ansible123!`
+
    c. 左側のサイドバーで**Resources** → **Templates**をクリックします。
+
    d. **Deploy PostgreSQL and PG Admin**という名前のテンプレートを見つけます。
+
    e. その行の右側にある**起動アイコン**（🚀ロケット船）をクリックします。
+
    f. ジョブが正常に完了するまで待ちます（緑色の「Successful」ステータスが表示されます）。

### オプション2: ansible-navigatorの使用

1.   **VS Codeでターミナルを開きます。**
+
    a. **VS Code**タブにいることを確認します。
+
    b. 上部のメニューバーを見て、**Terminal** → **New Terminal**をクリックします。
+
    c. ターミナルパネルがVS Codeの下部に開きます。

2.   **プレイブックフォルダに移動します。**
+
    ターミナルで、次のコマンドを入力し、`ENTER` を押します。
+
[source,bash]
----
cd playbooks/infra/install_pgsql_and_pgadmin
----

3.   **ansible-navigatorでプレイブックを実行します。**
+
    次のコマンドを入力し、`ENTER` を押します。
+
[source,bash]
----
ansible-navigator run demo_install_pgsql_pgadmin.yml
----
+
    プレイブックが実行され、結果が表示されます。完了したら `ESC` キーを押してターミナルプロンプトに戻ります。

## タスク4: PGAdminインストールの確認

最後に、PGAdminウェブインターフェースにアクセスできることを確認します。

1.   **PGAdminウェブインターフェースを開きます。**
+
    ラボ環境の一番上にある**PGAdmin**タブをクリックします。

2.   **PGAdminが実行されていることを確認します。**
+
    プレイブックが正常に完了した場合、PGAdminのログインインターフェースが表示されるはずです。これにより、PostgreSQLがインストールされ、PGAdminコンテナが正しく実行されていることが確認されます。
